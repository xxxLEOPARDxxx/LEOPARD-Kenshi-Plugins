# ModConfigMenu (MCM) — как добавить настройки своего плагина

MCM добавляет в окно «Настройки» игры вкладку **MCM**. Слева в ней список
модов, справа настройки выбранного мода, нарисованные родными строками игры
(DatapanelGUI): флажки, ползунки с полем для числа, выпадающие списки, поля
ввода. Пользователь меняет значение, MCM записывает его в ini вашего плагина
и вызывает вашу функцию, которая перечитывает настройки.

Ваш плагин от MCM **не зависит**. Без MCM он работает как раньше и читает
свой ini. Если MCM установлен, он сам находит плагин и строит для него
страницу.

---

## Что нужно

- Плагин RE_Kenshi на KenshiLib (DLL x64, VC10/v100, /MD), как обычно.
- Настройки в ini-файле, который читается через `GetPrivateProfile*`.
- Один заголовок: `ModConfigMenu.h` (лежит рядом с этим файлом). Линковать
  ничего не нужно: MCM вызывает плагин сам, а плагин MCM не вызывает.

---

## Три шага

### 1. Подключить заголовок

```cpp
#include "ModConfigMenu.h"
```

### 2. Сделать функцию, которая перечитывает ini

Скорее всего, она у вас уже есть: та, что читает ini при запуске. Нужно два
изменения:

- соглашение о вызове `__cdecl` (в x64 оно и так единственное, но тип
  указателя должен совпасть);
- функция должна быть **идемпотентной**: перед повторным чтением очищайте
  всё, что накапливается (списки, множества).

```cpp
void __cdecl LoadSettings()
{
    const std::string ini = IniPath();
    g_enabled = GetPrivateProfileIntA("MyPlugin", "Enabled", 1, ini.c_str()) != 0;
    g_radius  = GetPrivateProfileIntA("MyPlugin", "Radius", 50, ini.c_str());
    g_words.clear();          // накапливаемое - очистить
    // ...
}
```

### 3. Экспортировать `MCM_Describe`

Имя должно быть ровно `MCM_Describe`, без декорирования, поэтому нужен
`extern "C"`:

```cpp
extern "C" __declspec(dllexport) void MCM_Describe(MCM_Api* api)
{
    static const std::string ini = IniPath();   // строка должна жить, пока идёт вызов
    const char* const sec = "MyPlugin";

    api->beginMod(api, "MyPlugin", "My Plugin", ini.c_str(), &LoadSettings);
    if (api->version >= 2)
        api->info(api, Tr("What the mod does, in one or two sentences."));

    api->section(api, "General");
    api->toggle (api, sec, "Enabled", "Enabled", "Turns the plugin on and off.", 1, 0);
    api->integer(api, sec, "Radius", "Search radius, m", NULL, 50, 10, 500, 0);
    api->number (api, sec, "Scale", "Scale", NULL, 1.0f, 0.5f, 3.0f, 2, 0);

    static const char* const modes[]  = { "fast", "normal", "precise" };
    static const char* const labels[] = { "Fast", "Normal", "Precise" };
    api->choice (api, sec, "Mode", "Mode", NULL, "normal", modes, labels, 3, 0);

    api->section(api, "Advanced");
    api->hotkey (api, sec, "Hotkey", "Hotkey", NULL, "SHIFT+B", 0);
    api->colour (api, sec, "Colour", "Marker colour", NULL, "#E04030", 0);
    api->text   (api, sec, "Ignore", "Ignored words", NULL, "the,of", MCM_RESTART);
}
```

Всё. Пересоберите плагин, откройте «Настройки» и вкладку **MCM**.

## Справочник

Все строки в UTF-8. MCM копирует их во время вызова, хранить их у себя не
нужно. Подписи передавайте уже переведёнными (своим `Tr()` и т.п.). Язык
игры меняется только с перезапуском, так что перевести один раз достаточно.

| Функция | В ini пишется | Элемент |
|---|---|---|
| `beginMod(api, id, title, iniPath, apply)` | — | Начинает страницу мода. `id` — латиница, уникальный. `title` — подпись в списке модов: **оригинальное английское название мода**, без перевода. Если кому-то нужен перевод названий, его кладут в каталог самого MCM (`locale/<язык>/LC_MESSAGES/mod_config_menu.po`, msgid — это название). `iniPath` — **полный** путь к ini. `apply` — функция перечитывания, может быть `NULL`. |
| `info(api, text)` | — | С версии 2. Кратко, что делает мод: подсказка внизу окна при наведении на мод в списке. Уже переведённая. |
| `section(api, title)` | — | Подзаголовок внутри страницы. |
| `toggle(api, sec, key, label, tip, def, flags)` | `0` / `1` | Флажок. |
| `integer(api, sec, key, label, tip, def, min, max, flags)` | целое | Ползунок с полем ввода. |
| `number(api, sec, key, label, tip, def, min, max, decimals, flags)` | дробное, `decimals` знаков, точка | Ползунок с полем ввода. |
| `choice(api, sec, key, label, tip, def, values, labels, count, flags)` | одно из `values` | Кнопка с текущим вариантом: щелчок — следующий, SHIFT+щелчок — предыдущий (выпадающий список игры в игре выбор не отдавал). `labels` (видимые подписи) может быть `NULL`, тогда видны сами `values`. |
| `text(api, sec, key, label, tip, def, flags)` | строка как есть | Поле ввода. |
| `hotkey(...)` | строка (`"SHIFT+B"`, `"F12"`, `"ALT"`, `"NONE"`) | Захват: щелчок по кнопке, потом нажать клавишу или сочетание; модификатор сам по себе — тоже клавиша; Backspace — `NONE`. Разобрать строку в коде плагина — `shared/HoldKey.h` (`HoldKey::Parse`, `HoldKey::Held`). |
| `colour(...)` | строка (`"#RRGGBB"`) | Палитра (25 цветов, как в Mod Hub) и кнопка Hex для ввода кода; слово по умолчанию (`auto`) — отдельной кнопкой палитры. |

- `sec` / `key` — раздел и ключ ini (`[sec]` / `key=`). Разные настройки
  могут лежать в разных разделах одного файла.
- `tip` — подсказка при наведении на подпись, может быть `NULL`.
- `def` — значение по умолчанию: если ключа в ini нет и для кнопки «Сбросить
  по умолчанию».

**Флаги**

| Флаг | Что значит |
|---|---|
| `MCM_RESTART` | Значение вступает в силу только после перезапуска игры. К подписи добавляется звёздочка, к подсказке — пометка. |

## Как MCM себя ведёт

- **Когда вызывается `MCM_Describe`.** Один раз, когда игра впервые создаёт
  окно настроек (`OptionsWindow::create`). К этому времени все плагины
  RE_Kenshi уже загружены, поэтому порядок модов не важен. MCM перебирает
  загруженные DLL и вызывает `MCM_Describe` у каждой, где он есть. Вызов
  обёрнут в `__try`: если плагин упадёт, MCM запишет это в журнал и
  продолжит работу.
- **Несколько страниц.** Каждый `beginMod` начинает новую страницу. Один
  плагин может описать несколько модов, если ему так удобнее.
- **Чтение.** При открытии страницы значения читаются из ini заново
  (`GetPrivateProfileStringA`). Хвостовой комментарий `; ...` у нетекстовых
  значений отбрасывается. Числа обрезаются по `min`/`max`.
- **Запись.** Через `WritePrivateProfileStringA`: меняется только строка
  этого ключа, комментарии и прочие ключи остаются на месте. Флажки и списки
  записываются сразу. Ползунок — когда его 0,4 с не трогали. Текст — через
  0,8 с после последней правки. При закрытии окна настроек дописывается всё,
  что не успело.
- **`apply`.** Вызывается после записи, из главного потока игры (из
  обновления окна настроек). В нём перечитайте ini и примените, что можно
  на ходу. Тяжёлую работу туда не кладите. Если `apply` упадёт, MCM запишет
  это в журнал.
- **«Сбросить по умолчанию».** Кнопка внизу страницы. Пишет `def` во все
  ключи страницы и вызывает `apply`.
- **Ini без BOM.** Функции `*PrivateProfile*A` читают байты как есть. Если
  нужна кириллица или иероглифы, храните UTF-8 без BOM.

---

## Советы

- **Применяйте на ходу всё, что можно.** Что требует перезапуска (хуки,
  ставящиеся только при старте; таблицы, собираемые один раз), помечайте
  `MCM_RESTART`. Частый приём: хуки ставить всегда, а флаг `Enabled`
  проверять внутри хука. Тогда выключатель работает и без перезапуска.
- **Ключи ini должны совпадать.** Те, что вы передаёте в MCM, должны
  совпадать с теми, что читает плагин, включая регистр раздела.
- **Указатель `api` не храните.** Он действителен только во время вызова.
- **Исключения C++ через границу DLL не бросайте.**
- **Используйте `api->version`.** Если вам нужна функция из более новой
  версии API, проверьте `api->version`. Поля `MCM_Api` только добавляются в
  конец, старые не меняются.

## Настройки без ini: строки на функциях (версия 3)

Если плагин хранит настройки сам (JSON, свой формат) и сам их проверяет,
MCM может не трогать файлы, а звать функции плагина. Страница начинается
`beginMod` с `iniPath = NULL`, строки - вариантами с `Fn`:

```cpp
static int __cdecl GetRadius(void* ud, int* out) { *out = g_radius; return 0; }
static int __cdecl SetRadius(void* ud, int v, char* err, unsigned errSize)
{
    if (v < 10) { strcpy_s(err, errSize, "radius too small"); return 1; }
    g_radius = v; SaveMyJson(); return 0;
}
...
api->beginMod(api, "MyPlugin", "My Plugin", NULL, NULL);
api->integerFn(api, Tr("Radius"), Tr("Search radius, m"), &GetRadius, &SetRadius, NULL, 10, 500, 0);
```

| Функция | Значение |
|---|---|
| `toggleFn`, `integerFn`, `choiceFn` | целое (`MCM_GetIntFn` / `MCM_SetIntFn`); у `choiceFn` - массив чисел `values` и подписи |
| `numberFn` | дробное (`MCM_GetFloatFn` / `MCM_SetFloatFn`) |
| `textFn`, `colourFn` | строка (`MCM_GetTextFn` / `MCM_SetTextFn`) |
| `hotkeyFn` | клавиша `MCM_Key { keycode (OIS::KeyCode, -1 - нет), modifiers (MCM_KEY_CTRL/SHIFT/ALT) }`; в поле - текстом `CTRL+SHIFT+B`, `NONE` |
| `action` | кнопка; после нажатия страница перечитывается |

Возврат 0 - принято, иначе отказ: текст из `err` уходит в журнал, строка
показывает то, что вернул getter. Чтобы у такой страницы была кнопка
«Сбросить по умолчанию», после строки передайте её значение по умолчанию
(версия 5): `if (api->version >= 5) api->defaultValue(api, "1");` - строкой,
как MCM её понимает: 0/1, число, число варианта, текст, клавиша `CTRL+B`,
цвет `#RRGGBB`. Сброс отдаёт его через ваш setter. Сигнатуры совпадают с Mod Hub (EMC_*Callback): для модов на Mod Hub
есть готовый мост `McmModHubBridge.h`.

## Своя область на странице (версия 4)

Если плагину нужно показать не настройку, а данные (список, таблицу), он
просит у MCM область вверху страницы и рисует в ней сам:

```cpp
static void __cdecl Attach(void* ud, void* parent) { BuildMyList((MyGUI::Widget*)parent); }
static void __cdecl Detach(void* ud) { DestroyMyList(); }
...
if (api->version >= 4)
    api->customArea(api, &Attach, &Detach, NULL, 60);   // 60% высоты страницы
```

`attach` зовётся при показе страницы и при каждом новом открытии окна
настроек (данные можно перечитать), `detach` - когда со страницы ушли:
свои виджеты внутри `parent` плагин убирает сам. Строки настроек идут под
областью.

Открыть окно настроек сразу на своей странице (например, по своей клавише):

```cpp
MCM_OpenPageFn open = (MCM_OpenPageFn)GetProcAddress(GetModuleHandleA("ModConfigMenu.dll"), "MCM_OpenPage");
if (open) open("MyPlugin");   // id из beginMod
```

## Перед публикацией

- **Название страницы.** Пока страница выбрана, `title` из `beginMod`
  крупно стоит в заголовке окна настроек, на подложке. Длинное название
  растягивает подложку - держите его коротким.
- **Подсказки.** Точку в конце MCM убирает сам, `#` экранирует сам
  (иначе MyGUI принял бы `#RRGGBB` за смену цвета). Перенос строки - `\n`.
- **Символы.** В шрифтах игры (особенно в русской сборке, где шрифты
  подменены) есть только ASCII и кириллица. Длинное тире `—`, кавычки
  `«»`, многоточие `…`, `№` рисуются пустым местом. Пишите `-`, `"`,
  `...`, `No.`.
- **Зависимость необязательная.** В описании мода в Steam / на Nexus
  достаточно написать: «настройки в игре - с ModConfigMenu (не
  обязателен)». В «Required items» MCM добавлять не нужно.
- **Проверка.** `Debug=1` в `ModConfigMenu.ini`: в журнале должна быть
  строка `described by ...\ВашПлагин.dll`; затем пройдите страницу:
  каждую строку поменять, закрыть окно, открыть снова - значение на месте
  и в ini.

## Отладка

В `ModConfigMenu.ini` поставьте `Debug=1`. Тогда в `RE_Kenshi_log.txt`
появятся строки:

```
ModConfigMenu: described by ...\MyPlugin.dll
ModConfigMenu: 3 mod(s) with settings
ModConfigMenu: MyPlugin [MyPlugin] Radius=120
```

Если плагина нет в списке, проверьте, что `MCM_Describe` экспортирован без
декорирования: `dumpbin /exports MyPlugin.dll` должен показать ровно
`MCM_Describe`.
