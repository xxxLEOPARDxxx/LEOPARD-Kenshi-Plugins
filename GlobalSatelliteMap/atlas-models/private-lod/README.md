# One owned, unregistered cached town mesh

This helper accepts already-worker-read bytes from one actual native cached town mesh. It imports those bytes into an owned Ogre Mesh and returns the existing direct-D3D `AtlasModels::Packet`. It performs no file I/O, Entity/node/town creation, zone activation, shader draw, worker discovery or viewer integration. The supported current inventory is282 real `data/meshes/distant/distant_<container>.mesh` files; mapping them to the current town list remains caller work.

**The Mesh has creator=NULL and is not registered with any MeshManager or resource group.** A normal shared-manager load can call checkUsage and unload unrelated idle resources; explicit private groups also fall back to global same-name resources. Neither route is used here. The private group string is only the Resource's logical label. No shared memory budget or registration is changed.

## API

`Snapshot::Read(enabled,bytes,count,townId,generation,rawWorld16,sourceOrigin3,expectedDevice,verified,otherOwnedGpuBytes)` performs one explicit request. OFF returns S_FALSE before source/native queries; it invalidates an existing Packet's COM draw references but leaves owned Mesh retirement to explicit Clear. The caller MUST call `Clear()` once on disable/world/device/generation transitions, while Ogre is alive and on the serialized render thread. Do not call Read every window/frame.

`Geometry()` returns a borrowed const Packet, `Valid(generation)` its readiness, `Signature()` the stored native hexadecimal submesh-name signature, and `LastError()` a fixed bounded message. `OwnedGpuBytes()` is the conservative reservation described below; `CpuPayloadBytes()` reports bounded input/shadow/staging/name/State payload, not absolute process RSS. The caller must log failed results/errors. `Clear()` returns bool and its failure must also be reported.

`verified` must establish the current native module/code and DistantTown shader/material source identity, the selected bytes/hash/filename association with Town.handle.container, and the provenance of the supplied finite pose/origin/generation. The helper cannot infer those facts from a uint ID. Raw matrix/origin are copied separately; no automatic scene-origin addition, current-save fingerprint or exact unloaded-town Y is invented. The caller owns coordinate proof and cancellation before submitting the synchronous request.

The material must already exist and be loaded as DistantTown, with the supported original native programs and pass state. Its existing texture is inspected through the passive loaded-frame path; no active texture getter, material load or filename fallback is used. Only the diffuse SRV and a private sampler are retained by the successful Packet. Full native diffuse-resource retention is borrowed lifetime, separate from new mesh allocation. An absent/unsupported material/texture returns failure.

## Native lifetime and ABI

Actual Mesh constructor1A28F0 and nondeleting destructor1A2D40 operate on **our aligned inline0x390-byte storage**. The actual native Mesh factory allocates0x390, and SDK sizeof/alignment are0x390/8. Using external storage with the native constructor/destructor avoids an allocator/deleting-destructor mismatch. No Ogre SharedPtr owns that outer storage. Its creator is explicitlyNULL, handle0, manual=true and loader points to the owned loader. Identity checks require the exact inline address, native Mesh vtable, NULL creator, handle0 and private name/label before load/import/retirement.

Normal Resource::load270650 still executes the manual loader and normal Loaded state. Its creator-NULL branch skips shared-manager credit/checkUsage; unload270CF0 likewise skips creator debit. The loader wraps its owned bytes in the exact native96-byte MemoryDataStream with freeOnClose=false/readOnly=true. DataStreamPtr uses SPFM_NONE, so it never deletes the stack stream or input vector. An owned120-byte MeshSerializer starts with listenerNULL; its destructor runs before the stream destructor. Loader callbacks outside this explicit authorized load refuse.

On success, supported SubMesh LOD0/declarations/buffers are read from this owned Mesh, independently of registered-Town admission. Primary VB/IB descriptions must exactly match preflight. No live Town/Entity/scene pointer is retained. The published Packet contains copied data and COM references only. Full SDK ABI guards also check SharedPtr size16 and its native refcount field atinfo+20hex.

Retirement order is: clear Packet/sampler; verify inline ownership; native unload; native **nondeleting** Mesh destructor; then release loader/bytes/State. No remove(handle), group destruction, creator notification or original-resource unload is called. Normal C++ failures run cleanup. Native faults or uncertain cleanup invalidate the packet and poison the one global slot, refusing all future loads. If cleanup remains uncertain at owner destruction, that single State/loader/native allocation is intentionally retained until process exit rather than deleting live callback storage. This is bounded fault retention, not a universal corruption recovery or no-leak claim. The plugin must remain loaded; live module unloading is unsupported.

## Bounds and work

Input is at most512KiB. The production parser admits only the observed v1.100 one-submesh, one36-byte-stream layout: position0,normal12,UV24,packed colour32, triangles, finite ordered bounds and one hexadecimal signature. It rejects skeleton, animation, linked LOD/material and unknown dependency chunks before native import. Every one of the current282 files passes this preflight; their total primary VB/IB payload is7,123,782 bytes and maximum single payload337,122 bytes.

On successful `Parser::Read`, `BlobInfo.localBounds[6]` is an exact value copy of the validated native bounds chunk (minimumXYZ, maximumXYZ). It gives the file worker/caller local bounds for ModelRegion without hardcoded metadata or GPU readback. Use it only after true; false parser results are not publishable. This adds24 CPU bytes to BlobInfo and does not change GPU reservation or native resource APIs.

Native D3D11 hardware buffers may own a primary resource and shadow/temporary staging resources. The actual pinned constructor/lock paths allow at most one of each, with children system-memory/nonshadowed. Reservation is therefore **3× primary VB+IB bytes**, including potential staging even when absent. It is checked against authoritative `AtlasView::GpuCap` (192MiB) before import and after exact primary-size observation. Maximum current candidate reservation is1,011,366 bytes; maximum accepted blob reserves at most1.5MiB. The caller excludes only this one slot and includes every other cache/pending/renderer/model/decode/local/water allocation.

CPU payload includes input capacity, native shadow capacity, potential temporary staging capacity, fixed State (including912-byte Mesh storage), and private name capacities. Native allocator/container/driver/shader overhead is not an absolute measured bound. The global gate admits only one live request, and failure cannot create a growing queue. Resource creation/import/packet-state allocation occurs once per explicit request, not in Render. Native import/upload cost has not been measured in the game; do not preload all282 or promise zero frame cost.
