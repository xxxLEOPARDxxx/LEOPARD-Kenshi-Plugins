# Bounded native model decode/merge

New files only. Consume an already rendered256x256 native DistantTown GBuffer and an existing decoded256x256 terrain/model window. Reuse the production GBufferDecode.hlsl chroma reconstruction, actual radial-depth formula and an exactly validated top-down View. A caller-verified generation/origin/translation is mandatory; infer no absolute mapping. Decode into three reusable scratch UAV planes and copy back only after the complete dispatch. Keep existing decoded pixels for uncovered/invalid models or higher terrain. Reject ill-conditioned radial reconstruction and use a conservative arithmetic uncertainty interval for foreground comparison. Shared192MiB payload ledger includes three256² planes plus64B CB; no source/world queries, CPU readback, resource creation or heap allocations in Render. Real native Raster fixtures precede compiled negative controls. No game/install/main changes.
