# Worker-owned accepted-window GST2 session

`WorldWindowSession.h` is a bounded serialized **worker-only** bridge from actual `WorldPixels::Accepted` owners to fresh incomplete4x4 GST2 files. It uses the unchanged AcceptedWindow adapter and WindowWriter512. It creates no worker, scheduler, native API adapter, mip, index, COMPLETE flag or atlas readiness/publication. No Main/render/UI callback may perform these calls or release borrowed owners during a write.

## Exact addressing

Only512x512 windows at exactly9m are supported. Pixel0 is minimum world X/Z; total32768 pixels cover[-147456,147456] on each axis. For each axis, calculate `globalPixel=(double(center)-2304+147456)/9`; require an exact integer, divisible by512, in[0,32256]. Tile is globalPixel/8192 and local coordinate is globalPixel%8192. No tolerance, rounding, quantization or resampling is used. Canonical centers are `-145152+4608*k`, k0..63. All4096 positions are bounded to16 tiles. A window never crosses a tile boundary.

The first real fixture at(-16128,-16128) maps tile(1,1), local(6144,6144); the second at(-11520,-16128) maps local(6656,6144) in the same file. The older512/9m center-13824 is not512-aligned and is rejected. Fine1m/3m and256 windows are refused. This bridge does not validate arbitrary material-region continuity or generate the source pixels; Accepted remains the mandatory semantic/source-height gate.

## Public API and identity

`Factory` supplies a pure `FileCpuBound()const` and `OpenNew(tileX,tileZ)`. OpenNew transfers a fresh uniquely owned `Gst2::RandomFile*`, or returns NULL/throws on failure. It must create a **new** file (for real paths use CREATE_NEW, not replace/open-existing), return distinct objects, report an honest fixed upper bound for every file object's owned CPU payload, and keep methods/destructors non-reentrant; destructors must not throw. The session rejects an object pointer already owned in another tile. RandomFile cannot itself attest physical freshness/path safety; the integrating factory must be reviewed and must own only a new private output directory. This header has no default path, file-opening policy or existing-atlas overwrite API.

`Session::Begin(enabled,currentScope,atlasMaterialGeneration,factory,Ledger)` binds its owning worker thread. It is one-shot: an acquired session cannot be restarted or resumed after Close/poison. Scope's thread field remains the checked producer/Main metadata identity; it is **not** the writer worker ID. The separate owner thread is GetCurrentThreadId at Begin.

Source and capture stamps are exactly scope.sourceEpoch and scope.job; scope world/thread/source/job remain unchanged across the session. Frame.generation must equal that batch capture. The atlas-wide material/catalog generation is independently nonzero and must remain unchanged at every Write. Per-window Frame.materialGeneration is deliberately allowed to vary across regions/cohorts and is checked through the **exact fresh Accepted acquisition**. The caller must obtain/check the atlas-wide catalog generation and the window's material parameters/provenance. These tokens are not cryptographic native-resource winner proof and are not newly serialized into the legacy GST2 header.

`Write(enabled,accepted,currentScope,exactFrame,authHeightWindow,atlasMaterialGeneration,cancelEvent,Ledger,Location&written)`:

1. Reject foreign-worker access before file/controller mutation. OFF or stale scope/capture/catalog poisons the session. Cancellation checks precede coordinate/source work.
2. Derive the exact address; malformed shape/coordinates and duplicates refuse before adapter allocation or file IO. These harmless untouched refusals preserve the session for a corrected request. The output Location is zero on any refusal.
3. Admit the full CPU ledger, Build the shared normal adapter, and Acquire freshly against the actual Accepted owner/window/current context. MaterialFP16 RGB/gloss and source worldheight are borrowed unchanged; only the normal coverage copy is owned and its A is255.
4. Lazily create this tile's fresh file/writer, then synchronously write all three8/4/4B planes through the unchanged writer. Its data is flushed before its existing coarse ledger bits. Only after all three succeed and final cancellation remains clear is this window counted/completed. A duplicate never rewrites it.
5. Clear the adapter on every success/failure, retaining no Accepted/raw/source pointer between calls. Factory/file ownership alone persists. IO refusal, C++ exception, source acceptance failure or cancellation poisons all files, closes them, and disables resumption. Already written bytes remain incomplete; the caller owns removal/quarantine of that failed private directory. No rollback or readiness is claimed.

Require `hr==S_OK` to acknowledge a window; WindowCount is progress only while Healthy. Close withdraws healthy progress and closes all files. Error reports the last refusal; harmless preflight/CPU refusals can be retried, but poison is permanent. OFF Begin returns S_FALSE without consulting the factory or acquiring a worker. Foreign Write/Close returns E_ACCESSDENIED without mutating the owning session. Status is worker-only, or after a known join.

## Lifetime, cancellation and memory

Factory must outlive the active session and its file objects. Construct/use/Close on the same dedicated worker. Destruction must be serialized after that worker finishes; call Close on the worker before transferring destruction to Main so no file work occurs there. A session destructor also releases any remaining owned files in ordinary serialized worker scope.

Accepted owner, authenticated height Window and all acquisition contexts must remain valid and immutable throughout a synchronous Write, including virtual file callbacks. Main must hold the producer's borrow until known worker acknowledgement/join; it may signal a cancellation event, but must not Pump/Release/Clear the borrowed producer. A plain copied raw pointer/View cannot substitute for the actual Accepted/Window arguments. Event lifetime covers the entire call. There is no cross-thread Session mutation method. Underlying writer cancellation observes the event before each output row and publication; the session checks it after the final flush as well, preventing a late cancel from acknowledging success.

There is one shared adapter (maximum1MiB normal payload),16 fixed tile/writer slots and16x256 window bits. At most16 uniquely owned files/handles can coexist; no per-window metadata grows. `Reservation(fileCpuBound)` uses checked multiplication and returns `sizeof(Session)+16*bound`, or0 if unsupported/over64MiB. The session reserves all possible file objects even while only a subset is open.

At Write, the64MiB admission automatically counts that reservation,1MiB normal payload, this Accepted::OwnedBytes, authenticated Window payload and its object. `Ledger.retainedRaw` adds retained raw/readback capacities, and `Ledger.other` adds the factory, source/cache/worker state, other accepted windows, pending producer payloads and all remaining owned CPU payloads. Exclude auto-counted items from other. The adapter receives the corresponding session reservation charge without double counting its embedded owner object. Begin counts its reservation plus caller ledger; because no Accepted/Window is passed there, any already live producer owners must be included in the Begin caller ledger. These are explicit owned-payload charges, not CRT/stack/OS/RSS guarantees or an attestation that caller charges are honest. GPU budgets remain with the renderer/producer and are not raised.

## Reproduction and evidence

Run bundled Python `run_tests.py` with VC10 x64/SDK7.1. Missing fixtures are captured by this folder's own prepare_fixtures.py into ignored `_generated` only, using an owned WARP device and unchanged actual world raster/bank/shaders. The fullmap is authenticated by WorldHeight::Source before bounded sample reads. DDS/RGBA source upload authentication remains the original bank's code. No borrowed generator/output is run or rewritten. These are pinned base-snapshot/private WARP inputs, not live game source-winner acceptance.

Fresh `/O2` and `/Od` runs each pass8,775 primary controls: two aligned real WARP→actual Accepted windows, actual fresh Win32 GST2 file, all material/gloss/normal/coverage/height bytes read back at independently calculated offsets, all4096 canonical addresses, misalignment/extent/1m/3m rejection and duplicate suppression.524,288 stored heights also match an independent plane equation from literal ushort source triangles within0.00006103515625m. The temporary logical file is1,431,307,264B, but only two windows are submitted/read. It is closed and deleted in the owned `_generated` directory; exception/mutant unwinding also deletes only successfully CREATE_NEW-owned test paths. It is not a sparse-file or low physical allocation claim.

Each optimization also passes36,498 adversarial controls including26 IO false/exception cuts,13 real in-IO cancellation cuts (including final flush), pre-cancel, source/catalog/capture/world high32 changes, valid newly Accepted data from a different world, foreign worker calls, factory failures, exact CPU cap/one-byte excess/overflow and file destruction. An earlier fixture-scaffold failure was traced to VC10/O2 frame return initialization; its replacement uses explicit by-reference initialization. Acceptance/renderer contracts were not weakened.

Only one actual file/tile and these two material windows are exercised end to end. Source winner adapters, whole-world material seams, long-running1024-cohort scheduling, partial-directory cleanup/publication, mips/indexes and game IO latency remain outside this primitive. Independent review is required before integration. No game process, installed data, UI or INI was changed.
