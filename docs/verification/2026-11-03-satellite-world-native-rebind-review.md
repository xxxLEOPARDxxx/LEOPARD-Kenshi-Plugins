## Ownership and authority

The session owns the actual Cohort bound to itself and a replaceable frozen terminal StageAdapter. Rebind requires its own Idle controller, no active bank or replacement, then freshly Pumps that Idle boundary to observe a worker exit or source/world drain. This is actual controller state, not an external verified Boolean. Busy admission preserves the active provider/binding. The caller must nevertheless obey the external consumer contract: a falsely released/illegally destroyed borrow cannot be inferred from Idle.

Admitted replacement withdraws Ready and constructs/captures a fresh provider. The explicit old/new object overlap is bounded and charged. Invalid jobs, constructor exceptions, partial/late capture failure or exhausted positive binding range delete the previous/candidate provider and clear every output token. The old provider is not reused as a fallback. Recovery requires another known-idle fresh capture.

Public token profile is a documented proxy binding serial, not the native profile. Lookup compares the entire stamped snapshot/request before forwarding. Refresh passes the preserved original raw native snapshot and requires its complete unchanged answer before restamping. BeginBank admits a full unique same-SID15-role set, translates each entry back to original raw metadata, and delegates the original native profile/listener/group/path/alias semantics. Capture is allowed only inside the owned synchronous capture transaction for the exact current request. A stale WorkerRequest cannot recapture through a newly bound provider.

Main ownership is checked before native routing. Creation/destruction must also remain on checked Main; foreign destruction is unsupported. Cohort constructor inspection confirms it only stores provider/gate references and creates its plain GPU-owner shell, so the documented C4355 this-reference warning does not represent a callback during partial Session construction.

## Budgets, work and integration boundary

CpuReservation composes the cohort's complete reservation plus session storage excluding the embedded controller and twice sizeof(Owned), including overlapping old/new providers. The fake terminal's45,071,954B is a measured host instantiation, not a native/RSS estimate. Native uses its real type size. Caller jobs/tokens/writer/factory and other external payloads must be charged separately; add ExtraCpuPeakBytes to Borrowed.otherCpuBytes, not the complete cohort reservation a second time. Native/SDK/WIC/driver costs are not a hard process-memory bound.

Capture is bounded to at most4 selected SIDs/15 roles each, with the documented second metadata Capture pass and existing native profile validation. This performs no world-wide scan, TIFF rehash or renderer allocation, but Main latency across a whole1024-cohort build is unmeasured. Invoke it only at controlled cohort boundaries; this review proves no FPS/throughput or general leak claim.

Before ANY Cohort Pump/Cancel/ReleaseView/Shutdown/destruction or rebinding while a writer consumer is pending, signal that writer's cancellation and obtain known acknowledgement/join first. Unknown completion requires retaining the whole outer session/cohort and CPU/GPU debt. This module does not independently make an unreviewed parent safe. ReadyFor checks its documented scope/first-frame/plan tuple; current native winner/world/save/material authority remains with the checked Main adapter. Only the pinned base source profile is admitted.
