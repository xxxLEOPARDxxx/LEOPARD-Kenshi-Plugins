# Полный XP Info и Stack Sort под MCM

Поручение пользователя 30.10.2026 дополняет текущую приёмку Dynamic Factions.
Ограничение SkillLevelUpInfo только целыми повышениями отменено: требуется весь
XP Info 1:1. Stack Sort нужен отдельным MCM-форком с поддержкой Rotate Items.
Публичных загрузок до пользовательских Nexus-ссылок нет.

## XP Info

Первичный оригинал: https://www.nexusmods.com/kenshi/mods/2160,
semper1dem / Alexander; исходники заявлены в архиве, GPLv3. Сохранить автора,
источник и лицензию. Сначала матрица оригинальных функций, настроек и default.

- [ ] Все плавающие процентные прибавки, объединение сообщений и повышения.
- [ ] Панель текущих тренировок с полосами и штатным разделителем.
- [ ] floatingLabels, levelUpLabels, panelBars, maxRows, minPercent,
  announceEverySeconds, recentSeconds и подробный журнал через MCM.
- [ ] Совместимость прежнего INI, стабильная идентичность уже опубликованного
  SkillLevelUpInfo; отсутствие повторных уведомлений после загрузки.
- [ ] Проверить совместное использование LiveXpBars; избежать незаметного
  дублирования/перекрытия панелей и не менять другой мод без необходимости.
- [ ] Сверка поведения с оригиналом, RU/EN/CN, bounded callbacks, сборка и игра.

## Stack Sort

Оригинал: https://steamcommunity.com/sharedfiles/filedetails/?id=3813810734
и https://github.com/jacobericson/StackSort, Jakematt2004.

- [ ] Сохранить сортировку, H/W, варианты, переходы и отмену; настройки в MCM.
- [ ] Объединять совместимые разделённые стеки с проверкой native результатов,
  не терять предметы при частичном отказе и не использовать поглощённый указатель.
- [ ] Правильно учитывать сохранённую ориентацию и текущие размеры предмета,
  размещение/отмену и совместимость стеков. Без Rotate поддержка необязательна.
- [ ] Скрывать собственные кнопки там, где сортировка бессмысленна: одиночные
  специализированные слоты железа/кактусов и подобные контейнеры.
- [ ] Фоновому решателю передавать только копии простых данных; Native/MyGUI/Ogre
  доступны главному потоку. Отмена и поколение защищают закрытый/изменившийся GUI.
- [ ] Лицензия и credits, README EN/RU, UI RU/EN/CN, debug последним/default0,
  meaningful tests, VC10 ABI, проверка в игре, папка реальных скриншотов.

KenshiRotate уже экспортирует API v1, IsRotated/CanRotate/SetRotated/RefreshVisuals
в текущем исходнике и установленной DLL. Не дублировать существующий API.
SetRotated с NULL GUI используется после извлечения вещей для batch placement;
ненулевой GUI выполняет проверку размещения/откат. Общий GameData не изменять.

## Интеграция и выпуск

1. Реализация идёт независимо по двум каталогам, Root проверяет интеграцию.
2. Изолированные тестовые сборки, затем сверка экспортов/импортов и личных INI.
3. Один номер версии на выпуск; полного перещёлкивания версий после правок нет.
4. Подготовить ZIP/MO, README, стиль описаний и список поддержки MCM. Полная
   история изменений отдельно от публичного описания; credits и ссылки остаются.
5. Сначала пользователь публикует Nexus; Steam только после его ссылок.

Параллельная приёмка Dynamic Factions остаётся незавершённой: кандидат5
установлен, ожидается DF-cycle-current (копия autosave1, час97, казна14000,
7жил). Проверить доставку первой руды, реальную продажу, scoped work-skill UI,
сохранение с грузом/выручкой, повторную загрузку и старт новой игры.
