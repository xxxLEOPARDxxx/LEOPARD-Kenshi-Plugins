# Предпросмотр сохранений — активная задача UI Tweaks

Запрос пользователя01.11.2026. Последнее уточнение: **реализовать сейчас
параллельно со спутником, в UI Tweaks**. Файл сохранён по прежнему пути, чтобы
не терять ссылку из очереди; прежний отложенный статус отменён.

## Что должно получиться

При сохранении делать снимок игрового окна/кадра и связывать его с конкретным
слотом. При выборе слота в окне загрузки показывать соответствующий снимок
**под списком сохранений**, как на пользовательских скриншотах. Работает при
загрузке из главного меню и из уже запущенной игры. Не захватывать рабочий стол.
Момент захвата выбрать так, чтобы окно сохранения не закрывало саму сцену.

Плагин выбран пользователем: **UI Tweaks**. Отдельный новый плагин не создаётся.

Последнее уточнение пользователя после первого теста: **HUD, миникарта и
панели персонажей должны присутствовать**. Исключить только меню сохранения/
загрузки и закрывающее сцену меню. Первоначальный pre-GUI вариант ошибочно
исключал весь интерфейс; не считать это желаемым поведением. Не показывать
пользователю скрытие/мигание окон и не сбрасывать фокус/курсор ввода ради снимка.
Не вести постоянный покадровый захват. Запись превью подтверждать только после
реального успешного завершения сохранения.

В первом игровом тесте снимок появился и успешно привязался к ручному сейву,
но рамка была больше изображения и показывалась до выбора строки. Исправить:
рамка без больших пустых полей;
скрыта до настоящего выбора пользователя. Щелчок по уже автоматически
выделенной первой строке тоже считается выбором; поддержать клавиатуру и
индексы после сортировки списка.

Уточнение после успешного теста HUD (20:38–20:39): рамка и снимок должны
занимать всю ширину окна загрузки, а не ограничиваться шириной миниатюры640.
Увеличивать изображение только для отображения, сохранять пропорции и вписывать
по высоте, если экран низкий. Пустое состояние тоже выравнивать по полной ширине.
Ограничения записываемого файла/миниатюры от этого не увеличиваются.

Последние уточнения пользователя22:00–22:05 отменяют часть прежнего вида:

- Превью существующих слотов показывать в меню **сохранения**, а также загрузки.
- Окно поднимать сразу при открытии, оставляя место под снимком. Не двигать
  окно при переключении строк и не обрезать изображение.
- Без снимка не показывать ни рамку, ни текст «Нет снимка сохранения».
- Увеличить качество:640x360 недостаточно. Новая реализация сохраняет PNG без

Это актуальные требования; фраза о неизменном размере миниатюры выше относится
только к более раннему увеличению ширины отображения, не к последней правке качества.

## Требования, которые нужно учесть при реализации

- Миниатюра обновляется только после успешного сохранения; ошибка или отмена
  не должны заменить правильный снимок чужим/незавершённым кадром.
- Ручные сохранения, перезапись слота, quicksave и сменяемые autosave должны
  сохранять правильную связь изображения со слотом. Проверить переименование,
  удаление, перенос сохранений, другой каталог сохранений и повторную загрузку.
- Старые сохранения без снимка продолжают загружаться; показывать понятное
  пустое состояние. Изображение необязательно для работоспособности сейва.
- Предпросмотр вписывается в доступную область без искажения пропорций,
  учитывает масштаб интерфейса, разрешение, ванильный и модифицированные скины.
- Не снимать/декодировать изображение каждый кадр или при каждом наведении.
  Ограничить GPU readback, размер файла, очередь записи и кэш миниатюр.
  Игровые объекты/рендер остаются на штатном потоке; фоновой обработке передавать
  только принадлежащие модулю байты. Измерить задержку сохранения и память.
- Настройки MCM, три языка, журнал последним/выключен по умолчанию. Прочие
  переключатели и формат хранения определить после исследования штатного save/UI.
