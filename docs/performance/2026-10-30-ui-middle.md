# Middle geometry investigation, 2026-10-30

Installed MyGUI native disassembly and boundary fixtures established that six
stock status bars call Widget::setRealSize every frame. Their integer pixel
size is often unchanged, but the native IntSize setter invalidates geometry
and emits coordinate events. Equal EditText captions already have a native
guard; the historical contrary claim was incorrect.

UITweaks10 extends SkipSameMoves to the immediate native relative-size
conversion of a plain Widget. The original helper performs float conversion;
an exact-target TLS token lets the integer setter skip equal dimensions. The
token is consumed before callbacks and restored in finally. Explicit refreshes,
derived controls, changed pixels, parent clipping and reentrant callbacks retain
native behavior. No persistent widget cache or new worker thread is introduced.

Twelve native regression groups run through installed MyGUI geometry/crop/skin
functions. They include10000 equal updates, derived dispatch, real pixel changes,
parent clipping, explicit and reentrant refreshes, nested calls, toggle-off and
C++/SEH cleanup. Run UITweaks/tests/test_geometry.py on the configured stand.
